Database is Organised collectin of data:
- stored in a structured way
- Can be searched efficiently
- Can be Safely Shared by many users and application at the same time

Where does DB store data :
- db stores data in files on disk. 
- These disks can be HDD (Hard disk), SSP, cloud stores
- Inside db, data is stored in pages/blocks.(Here the machine itself breaks the data for us and store inside multiple pages & for every page we have a fixed number of records)
- Frequently used pages are cached in RAM
- DB uses B-tree/B+tree internally to search fast.
  > B-tree/B+tree for indexes
  > some times hash structure for lookups
  > buffer cache to avoid disk reads

→ Page is a fixed size block of storage

Select * from employees where id=3
db process :  disk > Land page containing row3 >Copy Page into RAM > search inside page > Return ROW

B-tree is a balanced tree Structure used to quickly locate data

-Think of it like a. decision tree
each number represents a key value in the index.
Most databases actually uses B+ trees

B-tree
-data stored in all nodes
- Harder ranges scan

B+ tree
-Data only in leaf  nodes
- Very efficient range scans
